Сохранённые JSON предыдущих запусков не переписывались; их готовые карточки требуют пересчёта при будущем импорте (API импорта сейчас отсутствует).

## Следующая итерация: проверяемый поиск пропусков

- `OPENAI_COVERAGE_ENABLED=true` разрешает coverage в normal/strict для всех успешно полученных транскриптов, а не только нулевых ответов detector. По умолчанию выключен; diagnostic сохраняет coverage.
- Поиск возвращает гипотезы. Их самоприсвоенный review удаляется перед отдельным локальным reviewer. Reviewer может отклонить находку или снизить её значимость; при сбое остаётся явный not_reviewed. Оба этапа проходят через scheduler; дополнительные запросы/токены и диагностические ответы учитываются.
- Coverage v3 допускает подтверждаемое повторное направленное воздействие с ясным distress, даже если мотив неясен. Одиночного «хватит» недостаточно. Moderate больше не принудительно заменяется на high.
- Reviewer v10 различает повторный distress и физическую опасность: при отсутствии подтверждённого вреда нельзя оставлять `violence/dangerous_situation` с `harmLevel=none`. Контекст может обосновать исправление в `disturbing_theme`, без придумывания травмы.
- Флаг включения и версия eval синхронизированы. Команда `npm run eval:coverage-replay` запускает платный локальный replay на сохранённых артефактах; это не независимый gold benchmark.

## Что делать следующим

1. Независимо разметить значимые и безобидные сцены на разных каналах: anchor, контекст, ожидаемое внимание, неоднозначность. Текущие provisional gold не считать человеческим эталоном.
2. На одинаковых реальных timeline сравнить повторные normal-прогоны и отдельный поиск пропусков, включая непустые ответы. Измерить пропуски значимых сцен, ложные главные предупреждения, задержку и стоимость. Выбрать стратегию coverage по этим результатам.
3. Исправлять оставшиеся случаи группировки сюжетов/смены ролей по воспроизводимым примерам, затем вводить возрастные предпочтения. Возраст не должен автоматически превращать игровые слова и мягкие насмешки в тревожные предупреждения.
